# Telegram Manager — личный ИИ-помощник в одном чате

Бот, через которого ИИ помогает навести порядок в Telegram:

- 📁 **раскладывает чаты по папкам** по смыслу (работа, семья, учёба, каналы…). Сначала показывает план, применяет только по кнопке «Применить»;
- 📝 **ведёт задачи и напоминания**: «напомни завтра в 10 позвонить маме»;
- 🔎 **сам находит задачи в переписке**: «ты обещал Ивану скинуть отчёт до пятницы». Каждую нужно подтвердить кнопкой;
- ☀️ **присылает утреннюю сводку**: что важного в непрочитанном и что сегодня по задачам;
- 🔍 **ищет по твоим чатам**: «найди, где Саша скидывал адрес»;
- 🧠 **даёт выбрать модель прямо в чате** и сам сообщает, когда появились новые.

Всё общение идёт **в одном чате с ботом**: команды, кнопки, напоминания, сводки и выбор модели.

## Как это устроено

```
 Ты  ⇄  чат с ботом  ⇄  помощник (этот проект)  ⇄  agy (Antigravity CLI) или Claude API
                              │
                              └── твой аккаунт Telegram (чтение чатов, папки)
```

- **ИИ.** По умолчанию помощник думает через **Antigravity CLI (`agy`)**: модели и лимиты берутся из
  твоего Google-аккаунта, отдельно платить за API не нужно. Вместо этого можно подключить Claude API
  (`AI_BACKEND=claude`).
- **Telegram.** Обычный бот не видит твои личные чаты и не может трогать папки. Поэтому помощник
  дополнительно входит в твой аккаунт как ещё одно устройство. Через аккаунт он **только читает**
  сообщения и **управляет папками**. Писать кому-либо или удалять чаты и сообщения он не умеет: этого
  нет в коде.

## Что понадобится

1. **Токен бота.** В Telegram открой [@BotFather](https://t.me/BotFather), отправь `/newbot`, придумай
   имя и скопируй токен.
2. **API ID и API hash аккаунта.** Зайди на [my.telegram.org](https://my.telegram.org) → *API development
   tools* → создай приложение (название любое) → скопируй `api_id` и `api_hash`.
3. **Antigravity CLI (`agy`)**, в который ты вошёл своим Google-аккаунтом (см. ниже).
4. **Компьютер, который работает постоянно**, иначе напоминания не придут. Помощник нужно запускать на
   той же машине, где установлен и авторизован `agy`. Нужен Python 3.10+.

## Установка и запуск

### 1. agy

```bash
curl -fsSL https://antigravity.google/cli/install.sh | bash      # macOS / Linux
# Windows (PowerShell): irm https://antigravity.google/cli/install.ps1 | iex

mkdir -p ~/.tgmanager/agy-workspace && cd ~/.tgmanager/agy-workspace
agy        # один раз: войти в Google-аккаунт и подтвердить доверие к этой папке, потом выйти
```

На сервере без браузера `agy` покажет ссылку: открой её на телефоне или компьютере, войди и вставь код
обратно в терминал.

### 2. Помощник

```bash
git clone https://github.com/ppmarkek/telegram-manager.git
cd telegram-manager
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env               # открой .env и вставь BOT_TOKEN, TG_API_ID, TG_API_HASH
python -m tgmanager check          # проверить, что agy отвечает (Telegram не нужен)
python -m tgmanager login          # один раз: телефон, код из Telegram, пароль 2FA
python -m tgmanager                # запуск помощника
```

После запуска открой своего бота в Telegram и нажми **Start**.

`python -m tgmanager check` проверяет по шагам: где лежит agy, его версию, список моделей, обычный
ответ, ответ в JSON и длинный запрос. Если что-то не так, там будет строка с ✗ и подсказкой.

### Через Docker (только для Claude API)

agy хранит вход в системном хранилище паролей, и в контейнере его сложно настроить. Поэтому Docker
подходит только для варианта `AI_BACKEND=claude`:

```bash
cp .env.example .env               # AI_BACKEND=claude и ANTHROPIC_API_KEY
docker compose run --rm tgmanager login
docker compose up -d
```

## Как пользоваться

Внизу чата есть кнопки **📁 Разложить чаты**, **📝 Задачи**, **☀️ Сводка**, **🧠 Модель**, **❓ Помощь**.
Ещё можно писать обычным текстом:

| Пишешь | Что происходит |
|---|---|
| напомни завтра в 10 позвонить маме | задача с напоминанием |
| что у меня на сегодня? | список задач |
| перенеси задачу 3 на пятницу 15:00 | перенос |
| разложи чаты по папкам | план папок с кнопкой «Применить» |
| объедини учёбу и курсы, каналы про крипту отдельно | исправленный план |
| можешь заменить мои папки | план, который заменит твои существующие папки (тоже только по кнопке) |
| найди, где Саша скидывал адрес | поиск по чатам |
| переключись на gemini pro | смена модели |
| присылай сводку в 8:30 / мой часовой пояс — Вильнюс | настройки |

Под напоминанием есть кнопки **✅ Готово**, **⏰ +1 час** и **🌅 Завтра в 9:00**.

### Модели и обновления

- **🧠 Модель** (или `/model`) показывает все модели, которые твой аккаунт может использовать в agy
  (тот же список, что выдаёт `agy models`). Нажми на нужную, и все следующие запросы пойдут через неё.
  Выбор сохраняется между перезапусками.
- У каждой модели свои лимиты. Если одна упрётся в лимит, бот так и напишет, а ты переключишься на
  другую.
- Раз в `AUTO_UPDATE_HOURS` часов (по умолчанию 12; первый раз через минуту после запуска) помощник
  запускает `agy update` и сравнивает список моделей с прошлым:
  - появились новые модели — пришлёт сообщение с кнопками, чтобы сразу на них переключиться;
  - agy обновился — напишет, с какой версии на какую;
  - выбранная модель пропала — вернёт модель по умолчанию и предупредит.
- `/update` — проверить обновления и новые модели прямо сейчас.

### Про папки

- Твои собственные папки помощник **не трогает**. Он создаёт свои в свободных местах:
  без Premium Telegram разрешает 10 папок по 100 чатов, с Premium — больше. Если хочешь, чтобы он
  заменил твои папки, скажи ему об этом явно.
- При повторной раскладке помощник сохраняет свою прежнюю структуру и добавляет в неё новые чаты.
- Архивные чаты не трогаются.

### Про поиск задач

Помощник раз в `SCAN_INTERVAL_MIN` минут смотрит новые сообщения:
- личные переписки (кроме ботов);
- в группах — только сообщения, где тебя упомянули или ответили тебе, и твои собственные (настройка
  `GROUPS_MODE`);
- каналы не читает.

Найденное приходит с кнопками **Сохранить** / **Не надо**. Без твоего подтверждения задача не появится.

## Настройки (`.env`)

| Переменная | По умолчанию | Что это |
|---|---|---|
| `AI_BACKEND` | `agy` | `agy` — Antigravity CLI, `claude` — Claude API |
| `AGY_MODEL` | — | модель по умолчанию (id из `agy models`); удобнее выбирать в чате |
| `AGY_BIN` | `agy` | путь к agy, если его нет в PATH |
| `AGY_WORKDIR` | `~/.tgmanager/agy-workspace` | пустая папка, в которой запускается agy |
| `AGY_TIMEOUT_MIN` | `10` | сколько ждать ответа agy |
| `AGY_SANDBOX` | `1` | запускать agy с `--sandbox` |
| `AUTO_UPDATE_HOURS` | `12` | как часто обновлять agy и искать новые модели; `0` — никогда |
| `ANTHROPIC_API_KEY`, `CLAUDE_MODEL` | — | только для `AI_BACKEND=claude` |
| `TIMEZONE` | `Europe/Moscow` | часовой пояс; можно поменять из чата |
| `DIGEST_TIME` | `09:00` | время утренней сводки или `off`; можно поменять из чата |
| `SCAN_INTERVAL_MIN` | `10` | как часто искать задачи в новых сообщениях |
| `GROUPS_MODE` | `mentions` | `mentions` / `all` / `off` — какие сообщения из групп читать |
| `EXCLUDED_CHATS` | — | id или @username через запятую. Эти чаты никогда не уходят в ИИ |
| `FOLDER_CONTEXT_MESSAGES` | `3` | сколько последних сообщений чата видит ИИ при раскладке |
| `MAX_CHATS_FOR_SORT` | `400` | сколько самых свежих чатов раскладывать |

## Безопасность и приватность

- **Файл `data/user.session` — это полный доступ к твоему аккаунту.** Не выкладывай его, не
  коммить и не пересылай. Если он утёк, завершить сессию можно в Telegram: *Настройки → Устройства*.
  `.gitignore` уже исключает папку `data/` и `.env`.
- Тексты сообщений, которые читает помощник, уходят в выбранный ИИ (Google через agy или Anthropic).
  Чаты, которые нельзя показывать ИИ, добавь в `EXCLUDED_CHATS`.
- **agy — это агент, у которого есть свои инструменты** (файлы, терминал). Помощник ограничивает его так:
  - запускает agy в пустой папке вне проекта, где нет ни `.env`, ни сессий;
  - передаёт флаг `--sandbox`;
  - прямо запрещает в запросе пользоваться инструментами;
  - не передаёт флаг «всё разрешать».

  Если в настройках самого agy включено `toolPermission: always-proceed`, помощник предупредит об этом
  при запуске: для него лучше оставить `request-review`.
- Тексты из чужих сообщений ИИ получает как данные, а не как команды. У помощника в принципе нет
  действий «написать кому-то» или «удалить», поэтому даже хитро составленное сообщение не заставит его
  это сделать. Изменение папок всегда ждёт твоей кнопки.
- Боту может написать любой, но команды он выполняет только для владельца аккаунта, в который вошёл
  помощник.
- Telegram не любит резкие массовые действия с аккаунта. Помощник делает паузы между запросами,
  но не запускай раскладку десятки раз подряд.

## Сколько стоит

- **agy:** расходуются лимиты твоего Google-аккаунта; посмотреть их можно командой `/usage` в самом
  agy. Одна раскладка нескольких сотен чатов — это один большой запрос. Поиск задач — один небольшой
  запрос раз в `SCAN_INTERVAL_MIN` минут, если были новые сообщения. Сводка — один запрос в день.
  Каждое сообщение боту — от одного до четырёх запросов.
- **Claude API:** платишь за токены по тарифам Anthropic, расход видно в консоли. Для моделей,
  которые это поддерживают, включён серверный fallback: если модель откажется отвечать по своим
  правилам безопасности, запрос повторится на запасной модели.

## Для разработчиков

```bash
pip install -r requirements-dev.txt
python -m pytest
```

Структура:

- `tgmanager/app.py` — чат с ботом, кнопки, выбор модели, фоновые задачи (напоминания, сводка, поиск задач, обновления);
- `tgmanager/ai.py` — общие промпты и схемы ответов, бэкенд Claude API;
- `tgmanager/agy.py` — бэкенд Antigravity CLI: запуск `agy -p`, JSON-ответы, `agy models`, `agy update`;
- `tgmanager/userbot.py` — чтение чатов и папки через аккаунт (Telethon);
- `tgmanager/folders.py` — проверка плана папок и лимиты;
- `tgmanager/storage.py` — SQLite: задачи, очередь сообщений, настройки;
- `tgmanager/timeutil.py` — время и часовые пояса.
