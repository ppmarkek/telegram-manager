# Telegram Manager — личный ИИ-помощник в одном чате

Бот, через которого ИИ (Claude) помогает навести порядок в Telegram:

- 📁 **раскладывает чаты по папкам** по смыслу (работа, семья, учёба, каналы…). Сначала показывает план, применяет только по кнопке «Применить»;
- 📝 **ведёт задачи и напоминания**: «напомни завтра в 10 позвонить маме»;
- 🔎 **сам находит задачи в переписке**: «ты обещал Ивану скинуть отчёт до пятницы». Каждую нужно подтвердить кнопкой;
- ☀️ **присылает утреннюю сводку**: что важного в непрочитанном и что сегодня по задачам;
- 🔍 **ищет по твоим чатам**: «найди, где Саша скидывал адрес».

Всё общение идёт **в одном чате с ботом**: команды, кнопки, напоминания и сводки.

## Как это устроено

```
 Ты  ⇄  чат с ботом  ⇄  помощник (этот проект)  ⇄  Claude API
                              │
                              └── твой аккаунт Telegram (чтение чатов, папки)
```

Обычный бот Telegram не видит твои личные чаты и не может трогать папки. Поэтому помощник
дополнительно входит в твой аккаунт (как ещё одно устройство). Через аккаунт он **только читает**
сообщения и **управляет папками**. Писать кому-либо или удалять чаты и сообщения он не умеет: этого
нет в коде.

## Что понадобится

1. **Токен бота.** В Telegram открой [@BotFather](https://t.me/BotFather), отправь `/newbot`, придумай
   имя и скопируй токен.
2. **API ID и API hash аккаунта.** Зайди на [my.telegram.org](https://my.telegram.org) → *API development
   tools* → создай приложение (название любое) → скопируй `api_id` и `api_hash`.
3. **Ключ Claude API.** [platform.claude.com](https://platform.claude.com) → *API Keys*. Использование
   оплачивается отдельно от подписки Claude.
4. **Компьютер или сервер, который работает постоянно**, иначе напоминания не придут. Подойдёт любой
   VPS или домашний ПК с Python 3.10+ или Docker.

## Установка и запуск

```bash
git clone https://github.com/ppmarkek/telegram-manager.git
cd telegram-manager
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env               # открой .env и вставь три ключа
python -m tgmanager login          # один раз: телефон, код из Telegram, пароль 2FA
python -m tgmanager                # запуск помощника
```

После запуска открой своего бота в Telegram и нажми **Start**.

### Через Docker (удобно для сервера)

```bash
cp .env.example .env               # заполни ключи
docker compose run --rm tgmanager login
docker compose up -d
docker compose logs -f             # посмотреть, что происходит
```

## Как пользоваться

Внизу чата есть кнопки **📁 Разложить чаты**, **📝 Задачи**, **☀️ Сводка**, **❓ Помощь**.
Ещё можно писать обычным текстом:

| Пишешь | Что происходит |
|---|---|
| напомни завтра в 10 позвонить маме | задача с напоминанием |
| что у меня на сегодня? | список задач |
| перенеси задачу 3 на пятницу 15:00 | перенос |
| разложи чаты по папкам | план папок с кнопкой «Применить» |
| объедини учёбу и курсы, каналы про крипту отдельно | исправленный план |
| можешь заменить мои папки | план, который заменит твои существующие папки (тоже только по кнопке) |
| найди, где Саша скидывал адрес | поиск по чатам |
| присылай сводку в 8:30 / мой часовой пояс — Вильнюс | настройки |

Под напоминанием есть кнопки **✅ Готово**, **⏰ +1 час** и **🌅 Завтра в 9:00**.

### Про папки

- Твои собственные папки помощник **не трогает**. Он создаёт свои в свободных местах:
  без Premium Telegram разрешает 10 папок по 100 чатов, с Premium — больше. Если хочешь, чтобы он
  заменил твои папки, скажи ему об этом явно.
- При повторной раскладке помощник сохраняет свою прежнюю структуру и добавляет в неё новые чаты.
- Архивные чаты не трогаются.

### Про поиск задач

Помощник раз в `SCAN_INTERVAL_MIN` минут смотрит новые сообщения:
- личные переписки (кроме ботов);
- в группах — только сообщения, где тебя упомянули или ответили тебе, и твои собственные (настройка
  `GROUPS_MODE`);
- каналы не читает.

Найденное приходит с кнопками **Сохранить** / **Не надо**. Без твоего подтверждения задача не появится.

## Настройки (`.env`)

| Переменная | По умолчанию | Что это |
|---|---|---|
| `TIMEZONE` | `Europe/Moscow` | часовой пояс; можно поменять из чата |
| `DIGEST_TIME` | `09:00` | время утренней сводки или `off`; можно поменять из чата |
| `SCAN_INTERVAL_MIN` | `10` | как часто искать задачи в новых сообщениях |
| `GROUPS_MODE` | `mentions` | `mentions` / `all` / `off` — какие сообщения из групп читать |
| `EXCLUDED_CHATS` | — | id или @username через запятую. Эти чаты никогда не уходят в ИИ |
| `CLAUDE_MODEL` | `claude-opus-5-5` | модель Claude |
| `FOLDER_CONTEXT_MESSAGES` | `3` | сколько последних сообщений чата видит ИИ при раскладке |
| `MAX_CHATS_FOR_SORT` | `400` | сколько самых свежих чатов раскладывать |

## Безопасность и приватность

- **Файл `data/user.session` — это полный доступ к твоему аккаунту.** Не выкладывай его, не
  коммить и не пересылай. Если он утёк, завершить сессию можно в Telegram: *Настройки → Устройства*.
  `.gitignore` уже исключает папку `data/` и `.env`.
- Тексты сообщений, которые читает помощник, отправляются в Claude API. Личные чаты, которые нельзя
  показывать ИИ, добавь в `EXCLUDED_CHATS`.
- Тексты из чужих сообщений ИИ получает как данные, а не как команды. У него в принципе нет действий
  «написать кому-то» или «удалить», поэтому даже хитро составленное сообщение не заставит его это
  сделать. Изменение папок всегда ждёт твоей кнопки.
- Боту может написать любой, но команды он выполняет только для владельца аккаунта, в который вошёл
  помощник.
- Telegram не любит резкие массовые действия с аккаунта. Помощник делает паузы между запросами,
  но не запускай раскладку десятки раз подряд.
- На случай отказа модели по фильтрам безопасности включён серверный fallback (`fallbacks: "default"`):
  запрос автоматически повторится на запасной модели.

## Сколько стоит

Платишь только за Claude API, тарифы на сайте Anthropic. При модели по умолчанию одна раскладка
нескольких сотен чатов — это примерно десятки тысяч токенов. Ежедневный разбор переписки и сводка при
обычной активности обходятся в небольшие суммы в день. Расход видно в консоли Anthropic. Чтобы
сэкономить, можно поставить в `CLAUDE_MODEL` более дешёвую модель (например, `claude-sonnet-5-5`);
качество раскладки и поиска задач при этом может стать хуже.

## Для разработчиков

```bash
pip install -r requirements-dev.txt
python -m pytest
```

Структура:

- `tgmanager/app.py` — чат с ботом, кнопки, фоновые задачи (напоминания, сводка, поиск задач);
- `tgmanager/ai.py` — запросы к Claude: структурированные ответы и инструменты помощника;
- `tgmanager/userbot.py` — чтение чатов и папки через аккаунт (Telethon);
- `tgmanager/folders.py` — проверка плана папок и лимиты;
- `tgmanager/storage.py` — SQLite: задачи, очередь сообщений, настройки;
- `tgmanager/timeutil.py` — время и часовые пояса.
